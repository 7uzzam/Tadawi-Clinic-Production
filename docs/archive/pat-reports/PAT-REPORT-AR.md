## ما تم تنفيذه في هذه الجولة

### 1. الفواتير والطباعة الحرارية
- إعادة هندسة CSS للحراري 58mm و 80mm: أعمدة `r-lbl` / `r-val` بدون التفاف غير ضروري
- تصغير الخط تلقائيًا للنصوص الطويلة (`rrow-long`) بدل كسر السطر
- `white-space: nowrap` للأسعار والكميات والإجماليات والضريبة
- QR متناسب مع عرض الورقة (48px لـ58mm، 54px لـ80mm)
- العنوان فقط (`r-meta-addr`) يسمح بالتفاف عند الضرورة

### 2. مراجعة النصوص والواجهة
- قواعد Typography للتبويبات، العناوين، النوافذ، الجداول
- `nowrap` + `ellipsis` للعناوين داخل البطاقات والـ Drawer
- PAT: 0 فيض نصي عند 1440px

### 3. Product Tour — ترخيص كامل
- **`sys_product_tour` معطّلة افتراضيًا** حتى في الإصدار الكامل
- ملف منفصل `cupping-product-tour.js` — **تحميل عند الطلب فقط**
- عند التعطيل: لا DOM، لا Styles، لا Listeners، لا أزرار
- لوحة المطور › التشخيص: تفعيل/تعطيل مباشر + Audit Log
- `licToggleRuntimeFeature()` للمطور

### 4. PAT
- 45 نجاح / 6 تحذيرات / 0 فشل
- التحذيرات: PDF/Electron، معالج بصري، تسميات EN مقصودة
