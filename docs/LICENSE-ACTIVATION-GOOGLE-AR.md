# التفعيل لمرة واحدة + Validation بدون سيرفر مدفوع

## المشكلة
المفتاح + رمز الفروع + Google يمكن بيعهم معاً. المطلوب:
- **تفعيل أول مرة** من جهاز رئيسي فقط
- **المفتاح لا يُستخدم مرتين** على جهاز مختلف
- **إعادة التثبيت** على نفس الجهاز: استرداد من Google
- **بدون سيرفر VPS** (تكلفة)

## الحل على 3 طبقات (مجاني)

### 1. الجهاز الرئيسي + `license.json` على Drive (مُنفَّذ)
| حدث | ماذا يحدث |
|-----|-----------|
| أول تفعيل | `activation.consumed=true` + بصمة الجهاز في `license.json` الموقّع → يُرفع على Drive |
| جهاز آخر + نفس المفتاح | يقرأ Drive → consumed + بصمة مختلفة → **مرفوض** |
| نفس الجهاز + مسح بيانات | ربط Google → سحب `license.json` → **استرداد** |
| أجهزة فرعية | سحب من Google (نفس حساب المركز) — لا تفعيل بمفتاح جديد |

### 2. Google Identity (مُنفَّذ)
المزامنة فقط مع حساب Google المرتبط بالترخيص.

### 3. Developer Vault — Google Apps Script (اختياري، مجاني)
- ملف: `scripts/google-license-vault.gs`
- Spreadsheet على حساب المطور = سجل التفعيلات
- Web App يستقبل `activate` / `status`
- **LockService** يمنع تفعيلين متزامنين
- التطبيق يرسل: `licenseId + fingerprint + deviceUuid + googleEmail`
- **لا يمكن** تمرير التفعيل مرتين لبصمة مختلفة

## سير العمل للعميل

```
[جهاز جديد — مفتاح فقط]
  → اربط Google (حساب المركز)
  → أدخل المفتاح
  → Gate: هل Drive فيه activation consumed?
      نعم + بصمة مختلفة → ❌ «مُفعَّل على جهاز آخر»
      لا → ✅ تفعيل + consumed + رفع Drive

[نفس الجهاز — بيانات ممسوحة]
  → اربط Google
  → «سحب الترخiص من Drive» (بدون مفتاح)
  → Gate: consumed + نفس البصمة → ✅ استرداد

[جهاز فرعي — فرع موجود]
  → Google + سحب + اختيار فرع + اسم جهاز
  → لا يحتاج المفتاح
```

## Owner Hub
يعرض: الجهاز الرئيسي، الفروع، الأجهزة المسجّلة، Google المرتبط.

## فرع واحد + عدة أجهزة
- **التفعيل الأول:** جهاز رئيسي (بصمة)
- **باقي الأجهزة:** Google + سحب — بدون مفتاح

## حدود (صريحة)
| سينario | النتيجة |
|---------|---------|
| بيع المفتاح فقط | ❌ لا تفعيل على جهاز ثانٍ |
| بيع المفتاح + Google الضحية | ⚠️ يستطيع سحب البيانات (امتلك حساب = امتلك كل شيء) |
| تغيير قطع الجهاز | قد تتغير البصمة — استرداد عبر Google أو المطور |
| Apps Script | مجاني ضمن حصة Google (~20k طلب/يوم) |

## تفعيل Apps Script (للمطور)
1. أنشئ Google Sheet: أعمدة `licenseId | status | fingerprint | googleEmail | consumedAt | deviceUuid`
2. الصق `google-license-vault.gs` في Apps Script
3. `Script Properties`: `VAULT_SHEET_ID`
4. Deploy → Web App → انسخ URL
5. ضع URL في إعدادات المطور (قادم: `developerVaultUrl`)
