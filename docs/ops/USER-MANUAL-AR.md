# دليل مستخدم تداوي المدينة 2.0

## الدخول والواجهة

افتح البرنامج من اختصار سطح المكتب، ثم أدخل حسابك. بعد خمس محاولات خاطئة يُقفل الحساب مؤقتاً. تعرض الواجهة حالة قاعدة البيانات والنسخ والمزامنة، ولا ينبغي تجاهل أي حالة حمراء قبل بدء العمل.

إذا كان المركز متعدد الفروع، اختر الفرع الذي تعمل فيه. لن تظهر إلا الفروع المسموح بها لحسابك، وقد يكون الحساب للقراءة فقط.

## دورة العمل اليومية

1. ابحث عن العميل برقم الملف أو الاسم أو الهاتف قبل إنشاء ملف جديد.
2. أنشئ الموعد وحدد الممارس والغرفة والمدة. يمنع النظام التعارض إلا بصلاحية وتبرير.
3. عند حضور العميل افتح الزيارة، راجع التاريخ المرضي والموافقات، وسجل الملاحظات وخطة العلاج ونقاط الحجامة.
4. أنشئ الفاتورة من الزيارة، راجع الخصم والضريبة والإجمالي، ثم سجل الدفعات. لا تحذف فاتورة صادرة؛ استخدم الإلغاء أو الاسترداد حسب الصلاحية.
5. اطبع على 58 أو 80 مم، أو A4/PDF. تأكد أن معاينة الطباعة تطابق المستند قبل الإرسال للطابعة.
6. أغلق الجلسة النقدية بعد مطابقة المتوقع والفعلي وكتابة سبب أي فرق.

## العملاء والسجل الطبي

- المرفقات المسموحة: صور وPDF حتى 25 ميجابايت. لا ترفع ملفات تنفيذية.
- الملاحظات الطبية والموافقات مقيدة بالصلاحية وتظهر في خط زمني.
- العميل قد يكون مشتركاً بين الفروع، لكن سجل الفروع الأخرى لا يظهر إلا وفق السياسة.
- استخدم التعديل والتوثيق؛ لا تنسخ بيانات المريض إلى تطبيقات خارجية غير معتمدة.

## المواعيد والمتابعة

الحالات تشمل: معلق، مؤكد، حضر، مكتمل، ملغي، ولم يحضر. عند إعادة الجدولة يحتفظ النظام بالتاريخ السابق والسبب. قائمة الانتظار والمتابعة تستخدمان لتعبئة الشواغر وتذكير العملاء.

## الاستيراد والتصدير

الاستيراد يدعم CSV وExcel وJSON ونسخ التوافق. اختر خريطة الحقول ومفاتيح التكرار ثم نفذ «معاينة» أولاً. راجع المرفوضات والمكررات، واستخدم Dry Run للملفات الكبيرة. لا تثبت دفعة قبل حفظ تقرير المعاينة.

## النسخ والمزامنة

- أنشئ نسخة مشفرة يومياً واختبرها دورياً. نجاح الرفع السحابي لا يغني عن نسخة محلية.
- عند انقطاع الشبكة يستمر العمل محلياً وتدخل التغييرات طابور المزامنة.
- التعارضات المالية أو الحذف مقابل التعديل تحتاج مديراً؛ لا تعالجها بتكرار السجل.
- إذا ظهرت جلسة منتهية، أعد تسجيل الدخول. لا ترسل ملف الرمز أو بيانات التفعيل عبر قنوات عامة.

## الخروج والدعم

أغلق العمليات الجارية ثم سجل الخروج. عند الإبلاغ عن مشكلة أرسل وقت الخطأ، الشاشة، الخطوات، ورقم الحدث إن ظهر. لا ترسل اسم مريض أو رقم هوية أو كلمة مرور أو مفتاح ترخيص في لقطة الشاشة.
